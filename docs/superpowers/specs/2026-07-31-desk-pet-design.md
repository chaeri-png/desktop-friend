# 뱁새 데스크펫 — 디자인 문서

- 날짜: 2026-07-31
- 상태: 승인됨 (사용자 확인 완료)
- 프로젝트 위치: `클로드코드 공용(픽사)/뱁새-데스크펫/`

## 개요

화면 구석에 상주하는 데스크탑 펫 앱. 캐릭터(v1은 임시 뱁새)가 뽀모도로 타이머와 하루 일과를 함께해 주고, 휴식 시간에는 화면을 떠다니며 춤추고 논다. ENA의 Phindoll(joelgc.com 데스크펫)에서 영감.

- 사용 대상: 픽사 팀 내부 공유 → 추후 외부 배포 가능성
- 플랫폼: Windows + macOS
- 기술: **Electron** (투명·프레임리스·항상 위 창 지원이 가장 검증됨. 용량 큰 것은 내부 배포에서 수용)

## 핵심 요구사항

1. 뽀모도로 타이머 — 집중/휴식 시간 분 단위 커스텀(기본 25/5), 캐릭터가 집중/휴식 상태를 표현
2. 유휴 랜덤 모션 — 가만히 있을 때 꿈틀, 하품, 짧은 춤 등
3. 클릭/드래그 인터랙션 — 클릭 리액션, 드래그로 위치 이동
4. 말풍선/알림 — 정시 알림, 응원, 물 마시기 등 잔소리 (끄기·빈도 조절 가능)
5. 하루 일과 — 할 일 입력 시 캐릭터가 현재 할 일을 말풍선으로 표시
6. 멀티 캐릭터 — 캐릭터 팩 폴더만 추가하면 새 캐릭터 선택 가능. v1은 임시 **뱁새** 1종
7. 화면 행동 — **평소엔 구석 고정**, 휴식 시간·요청 시에만 화면을 떠다님

## 전체 구조

창 2개 + 트레이 아이콘:

1. **펫 창** — 투명·프레임리스·항상 위(always-on-top)의 작은 창. 평소 화면 구석 고정, 휴식/요청 시 화면 위를 부드럽게 이동. 드래그로 위치 변경. 말풍선은 이 창 안에서 캐릭터 옆에 표시되고 몇 초 후 자동 소멸.
2. **설정 창** — 캐릭터 우클릭 또는 트레이 메뉴로 열리는 일반 창. 뽀모도로 시간 설정, 캐릭터 선택, 알림 on/off·빈도, 하루 일과 입력.
3. **트레이 아이콘** — 펫 숨기기/보이기, 타이머 시작/정지, 종료. (발표 중 등 잠깐 치울 때 사용)

부팅 시 자동 시작 옵션 제공(기본 꺼짐).

## 캐릭터 시스템

캐릭터 = 폴더 단위 "캐릭터 팩". 코드 수정 없이 폴더 추가만으로 캐릭터 추가.

```
characters/
  baepsae/            ← 임시 뱁새 (v1 기본)
    character.json    ← 이름, 상태별 애니메이션 정의(프레임, 간격)
    idle.png / focus.png / rest.png / dance.png / drag.png ...
```

- 이미지 형식: 낱장 스프라이트(PNG) 또는 GIF/APNG 모두 지원
- 상태 머신: 유휴(랜덤 모션 포함) / 집중 / 휴식(떠다니기) / 드래그 중 / 클릭 리액션
- v1 임시 뱁새는 단순한 그림으로 제작하고, 실제 그림이 나오면 이미지 교체

## 뽀모도로 + 하루 일과

**뽀모도로**
- 집중/휴식 분 단위 자유 설정, 기본 25/5
- 시작 → 집중 모드(남은 시간 표시) → 종료 시 말풍선 + 시스템 알림 → 휴식 모드(떠다니기·춤) → 휴식 종료 시 자동 반복 또는 물어보기(설정 가능)

**하루 일과** — 항목마다 시간 지정은 선택사항 (두 방식 혼용 가능)
- 시간 지정 항목: 해당 시각에 캐릭터가 말풍선으로 자동 알림 ("3시예요! 회의 갈 시간~")
- 순서만 있는 항목: 현재 항목을 말풍선에 표시 ("지금 하는 일: 제안서 쓰기") → 캐릭터 클릭으로 완료 처리 → 축하 모션 → 다음 항목
- 뽀모도로 연동: 현재 일과 항목 + 타이머를 함께 표시 ("제안서 쓰기 집중 중 · 12분 남음")

**말걸기(잔소리)** — 일과·타이머와 별개로 물 마시기, 스트레칭, 응원 멘트를 랜덤 출력. 설정에서 끄기/빈도 조절.

## 데이터 저장·배포

- 설정과 일과는 각자 컴퓨터 로컬 파일로 저장(서버 없음)
- 일과는 날짜 단위. "어제 일과 불러오기" 버튼 제공
- 배포: Windows `.exe` 설치 파일 + macOS `.dmg`. Mac 무서명 배포 시 최초 실행 "우클릭 → 열기" 안내문 동봉. 외부 배포 단계에서 코드 서명 추가 검토

## 테스트·검증

- 타이머, 일과 진행, 상태 머신 등 로직은 단위 테스트
- 투명 창·트레이·알림 등 OS 연동은 Windows에서 직접 실행 확인 (Mac은 팀원 기기에서 확인)
