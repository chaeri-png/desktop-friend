# 뱁새 3D 리디자인 — 디자인 문서

- 날짜: 2026-07-31
- 상태: 승인됨 (사용자 확인: "좋아 일단 진행해봐줘")
- 선행 문서: `2026-07-31-desk-pet-design.md` (v1 전체 디자인 — 이 문서는 캐릭터 표현·조작만 변경)

## 배경

v1의 뱁새는 베이지색 참새형 2D SVG였는데, 사용자가 원한 뱁새는 **흰머리오목눈이**(시마에나가, Aegithalos caudatus)였다. 위키미디어 커먼즈 사진으로 실물 확인 완료. 캐릭터를 실물 기반 **3D**로 전면 교체한다.

## 실물 관찰 (위키미디어 커먼즈 사진 기준)

- 몸 전체가 눈덩이처럼 새하얗고 동글동글, 머리·몸 구분 없는 한 덩어리
- 아주 작은 까만 점 눈, 아주 짧고 작은 까만 부리
- 검정 날개 + 어깨의 분홍 살구색 패치
- 몸길이만큼 긴 검은 꼬리(가장자리 흰 줄), 짧은 까만 다리

스타일 방향: 실물보다 몸은 더 크고 둥글게, 부리·다리는 더 작게 — **최대한 동글동글·귀엽게** (사용자 요청).

## 기술 선택

**Three.js를 펫 창에 넣고 구 조합으로 코드 모델링** (승인됨).

- 외부 3D 파일 불필요 → 색·크기·표정을 코드에서 바로 수정 가능
- three.module.js를 `src/renderer/vendor/`에 복사(번들러 없이 ESM import, 패키징에도 포함됨)
- 대안 기각: 무료 glTF(모델 없음·라이선스 불확실), Blender 제작(팀에 3D 작업자 없음)

## 조작 (사용자 선택: "드래그=돌리기, 이동은 길게 누르기")

| 조작 | 동작 |
|---|---|
| 드래그 | 뱁새 회전 (yaw 자유, pitch 제한). 놓으면 잠시 후 천천히 정면 복귀 |
| 길게 누르기(400ms) 후 드래그 | 창 위치 이동 (기존 drag-start/move/end IPC 재사용) |
| 클릭 | 인사 리액션 (기존) |
| 더블클릭 | 현재 일과 완료 (기존) |
| 우클릭 | 컨텍스트 메뉴 (기존) |

제스처 판별(클릭/회전/길게눌러이동)은 순수 모듈 `src/shared/gesture.js`로 분리해 단위 테스트한다.

## 3D 모델 구성 (bird3d.js)

- 몸: 큰 흰 구(살짝 눌린 형태), 부드러운 톤 셰이딩
- 눈: 까만 작은 구 2개 / 부리: 아주 작은 까만 원뿔
- 날개: 양옆 납작한 검정 타원체 + 어깨 분홍 패치
- 꼬리: 뒤로 길게 뻗은 납작한 검정 판 + 흰 가장자리
- 다리: 아주 작은 까만 원기둥 2개
- 집중 머리띠: 빨간 토러스(focus에서만 표시)
- 조명: ambient + directional, 배경 투명

## 상태 → 3D 애니메이션 매핑

기존 `view.animation` 채널 계약 유지 (main.js 무변경 원칙):

| 상태 | 3D 표현 |
|---|---|
| idle | 숨쉬듯 통통(사인 bob) + 몇 초마다 눈 깜빡 + 가끔 고개 두리번 |
| idleFun | 제자리 빙글 회전 + 통통 |
| focus | 빨간 머리띠 표시, 느린 bob, 살짝 앞으로 기울임 |
| rest | 빠른 통통 + 계속 빙글빙글 (창 로밍은 기존 main.js 그대로) |
| drag | 놀란 눈(눈 확대) + 파닥임 |
| react | 폴짝 점프 1회 |
| cheer | 점프 + 빙글 + 반짝 |

## 캐릭터 팩 구조 확장

- `character.json`에 `"type": "3d"` 추가. `type`이 없으면 기존 2D 프레임 방식으로 동작(하위 호환).
- pet.js는 type에 따라 2D 플레이어 또는 3D 플레이어(bird3d.js)를 선택.
- 2D 캐릭터 팩 추가 방식은 그대로 유지.

## 바뀌지 않는 것

뽀모도로·하루 일과·말풍선·잔소리·설정 창·트레이·저장소 — 전부 유지. 렌더러(펫 창)와 캐릭터 팩만 변경. main.js는 IPC 계약 변경 없음.
